# Student Placement Analysis Dashboard using Power BI

## 📌 Project Overview

This project is a **Student Placement Analysis Dashboard** developed using **Power BI**.
The dashboard helps analyze student placement performance based on academic scores, technical skills, internships, projects, communication skills, certifications, and other employability factors.

The main goal of this project is to identify the key factors influencing student placements and provide actionable insights for improving placement outcomes.

---

# 📊 Dashboard Modules

## 1️⃣ Overview Analysis

This section provides a high-level summary of placement statistics.

### Key Metrics:

* Total Students
  
* Placed Students
  
* Average CGPA
  
* Placement Percentage

### Analysis Included:

* Placement Status
  
* Branch-wise Placement Analysis
  
* Gender-wise Placement Analysis
  
* CGPA Category Analysis
  
* Placement Percentage by Branch

---

## 2️⃣ Performance Analysis

This section focuses on academic and practical performance factors affecting placements.

### Analysis Included:

* Internship Experience vs Placement
  
* Project Category vs Placement
  
* Coding Skills vs Placement
  
* Backlogs vs Placement
  
* Internship and CGPA Combined Analysis

---

## 3️⃣ Skills & Score Analysis

This section analyzes employability skills and score-based performance.

### Analysis Included:

* Aptitude Test Score Analysis
  
* Soft Skills Analysis
  
* Communication Skills Analysis
  
* Certification Analysis

# 🔍 Data Cleaning & Transformation

The following preprocessing steps were performed using **Power Query**:

* Checked missing/null values
  
* Removed duplicate records
  
* Changed data types
  
* Created calculated columns
  
* Created DAX measures
  
* Categorized CGPA, internships, coding skills, and projects

---

# 📈 Exploratory Data Analysis (EDA)

EDA was performed to understand patterns and trends in the dataset.

### Key Findings:

* IT and CSE branches have higher placement rates
  
* Students with internships perform better
  
* Coding skills strongly influence placements
  
* Students with fewer backlogs achieve better outcomes
  
* Communication and soft skills improve employability
  
* Certifications increase placement readiness

---

# 💡 Business Insights

* Placement success depends on both academics and skills
  
* Practical exposure improves employability
  
* Technical skills and coding ability are major placement drivers
  
* Students with strong communication and soft skills perform better in interviews
  
* Backlogs negatively affect placement opportunities
